## Recommended Résumé Version

- Designed and developed AP Path Planner, a full-stack academic planning application for high school students managing AP coursework.
- Built course, assignment, study-session, calendar, grade-tracking, reminder, profile, and data-management workflows using Next.js, React, TypeScript, and Firebase.
- Implemented Firebase Authentication, per-user Cloud Firestore storage, and Firestore Security Rules to restrict access to private academic data.
- Created automated testing across unit logic, Firestore Rules, authenticated Playwright workflows, accessibility checks, production builds, and deployed-site smoke tests.
- Configured GitHub Actions and Vercel deployment workflows and debugged differences between emulator, local production, Preview, and Production environments.
- Publicly launched the application and began collecting student feedback to guide future feature development.
