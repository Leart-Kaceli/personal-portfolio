# AP Path Planner Evidence Checklist

## Application Evidence

- [x] Live application URL works
- [x] Signup works
- [x] Login works
- [x] Major features work
- [x] Mobile layout works

## GitHub Evidence

- [x] Repository is public
- [x] README is polished
- [x] Git history is visible
- [x] Commit history is authentic
- [x] Source code is accessible
- [x] No private secrets exposed
- [x] GitHub Actions history visible

## Portfolio Evidence

- [x] Homepage includes AP Path Planner
- [x] Projects page includes AP Path Planner
- [x] Full technical case study exists
- [x] Screenshots included
- [x] GitHub link works
- [x] Live project link works

## Engineering Evidence

- [x] Firebase Authentication exists
- [x] Cloud Firestore exists
- [x] Security Rules exist
- [x] Security Rules tests exist
- [x] Playwright tests exist
- [x] Emulator tests exist
- [x] Accessibility tests exist
- [x] Production tests exist
- [x] Deployment checks exist
- [x] CI workflow exists

## Launch Evidence

- [x] Product Hunt launch URL
- [x] Reddit launch posts
- [x] Analytics screenshots
- [x] User feedback saved
- [x] Product improvements recorded

## College Application Claims

Every claim should be supported by at least one of:

- Live application
- Source code
- Git history
- Analytics
- User feedback
- Public launch page
- Test output
- Documentation

## Claims Not Allowed Without Evidence

Do not claim:

- Thousands of users
- Hundreds of students
- Major school adoption
- Improved student grades
- Increased AP scores
- Used by multiple schools
- Large-scale impact
- Revenue
- Company/team leadership
- AI features that do not exist

unless documented evidence exists.
