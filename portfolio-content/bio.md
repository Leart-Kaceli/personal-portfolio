# Full About Page Draft

## Introduction

I am a high school student interested in computer science, software engineering, and building technology that solves practical problems. I enjoy creating applications that are useful, organized, and reliable rather than adding features only for appearance.

## Why I enjoy programming

What interests me most about programming is the process of turning an unclear problem into a working system. A project begins as an idea, but completing it requires breaking that idea into smaller parts, making design decisions, debugging failures, and improving the result over time. I enjoy that combination of creativity, logic, and problem-solving.

## Building AP Path Planner

My largest project so far is AP Path Planner, a full-stack planning application designed for AP students. I created it to bring courses, assignments, study sessions, grades, goals, calendars, and reminders into one organized platform. I developed the application with Next.js, TypeScript, React, Firebase, Playwright, and other modern development tools.

## What the project taught me

Building AP Path Planner changed how I think about software development. I learned that a finished application needs much more than a working interface. I had to manage authentication, protect private user data, write and test Firestore Security Rules, create automated browser tests, improve accessibility, handle deployment environments, and debug differences between local and production behavior.

## Future direction

I plan to continue improving AP Path Planner based on feedback from real students. I am also interested in building projects involving artificial intelligence, education technology, productivity, financial tools, and applications that connect software with real-world needs.

## Detailed

AP Path Planner is a full-stack planning application designed for students managing demanding AP coursework. I built the application with Next.js, TypeScript, React, Firebase Authentication, Cloud Firestore, Tailwind CSS, Playwright, Vitest, GitHub Actions, and Vercel. The project includes secure per-user data, Firestore Security Rules, automated tests, accessibility checks, production monitoring, account-data controls, and deployed smoke testing.

# Why I Built AP Path Planner

AP students often use separate tools for assignments, grades, study schedules, calendars, and academic goals. I wanted to build one application that connected those responsibilities and made it easier to understand what needed attention. The project also gave me an opportunity to learn the complete process of developing, securing, testing, and deploying a full-stack application.


# Technical Challenge Preview

One of the most difficult parts of AP Path Planner was creating reliable testing for authenticated Firebase data. The browser tests needed a consistent test user, saved authentication state, Firebase emulators, controlled database cleanup, and tests that did not interfere with one another. Solving this taught me how authentication, browser state, database security, and automated testing interact in a production application.
